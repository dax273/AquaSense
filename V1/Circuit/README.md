# AquaSense V1 Circuit

This folder contains the circuit and wiring information of the first working AquaSense prototype.

## Components

- Arduino
- TDS sensor
- DHT22
- Ultrasonic sensor
- OLED display

## Pin Configuration

| Component | Arduino Pin |
|---|---|
| DHT22 Data | D2 |
| Ultrasonic TRIG | D4 |
| Ultrasonic ECHO | D3 |
| TDS Sensor | A0 |
| OLED SDA | A4 |
| OLED SCL | A5 |
